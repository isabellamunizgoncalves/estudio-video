# /roteiro

Siga a skill `/estudio` só até a etapa 3:
1. Entrada: canal, tema, link do YouTube e idioma (pergunte o que faltar numa mensagem só; o idioma sempre explícito). Crie o projeto se não existir.
2. `analista-emocional` → `roteirista` ⇄ `revisor-roteiro` (até 3 voltas, até `APROVADO`) → mostre o roteiro para aprovação.
3. Aprovado: `humanizador`.
- Se Isabella já tiver o roteiro: salve-o sem mudanças como `02_roteiro/roteiro_v01.txt`, ofereça o parecer do `revisor-roteiro` e siga para o `humanizador`.
4. Entregue: resumo emocional (4 linhas, sem citar comentários), blocos, nota do revisor, caminhos de `roteiro_vNN.md`, `roteiro_vNN.txt` e `roteiro_narracao_vNN.txt`. Próximo passo: `/narracao`.
